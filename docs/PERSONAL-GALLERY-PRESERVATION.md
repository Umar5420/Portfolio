# Personal gallery preservation

The main gallery includes all 25 original personal image assets from the Phase 19 archive, in addition to the seven supplied project screenshots. Personal photographs are kept as their own entries and are not replaced by project screenshots.

The project screenshot entries are separately titled and categorized. Duplicate references to the same image path are deduplicated; the underlying image files are preserved.

To install dependencies and build locally:

```bash
npm install
npm run build
```

A production build could not be completed in the packaging environment because the Vite executable was unavailable.
